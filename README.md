# AstroMode
a simple taskbar icon to toggle astrophotography related laptop settings

### Features
- red night filter
- brightness slider
- cpu power limiter
- prevent automatic standby, sleep, shutdown & restart
- display timeout
- always on USB ports
- lid close action

---
The app will automatically notify you once there is a new version and ask you to download it. It will reopen automatically.
